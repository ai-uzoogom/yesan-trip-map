# 스플라스 리솜 온천 여행 지도

2026년 11월 18~20일 용인–예산 여행 지도입니다. 지도 왼쪽과 오른쪽을 탭해 이전·다음 장소로 이동합니다. 각 구간은 거리에 관계없이 2.5초에 이동합니다. 도착하면 지도 아래에 장소 카드가 나타납니다.

## 실행과 데이터 수정

- 브라우저에서 `yesan_trip_planner.html`을 열면 됩니다. GitHub Pages는 기본 브랜치 루트의 `index.html`을 사용합니다. 설치와 빌드가 필요 없습니다.
- `trip-data.js`에서 장소, 예정 시각, 설명, 장소별 일러스트, 이동 순서와 구간 색상을 수정합니다. 좌표는 WGS84 `[경도, 위도]`입니다. 장소가 달라지는 연속 일정에는 `출발지ID-도착지ID` 구간을 등록합니다. 예당호의 출렁다리·음악분수·모노레일은 한 장소의 `activities`에 표시합니다.
- `map-data.js`에는 지도 도식, 개략 이동선, 준비된 도로 경로가 있습니다. `map.js`가 지도와 이동점을 그리며 `player.js`가 날짜별 재생, 카메라, 컨트롤과 경로 설정을 연결합니다.
- 장소 카드는 생성 일러스트를 표시합니다. 내장 ImageGen 프롬프트는 ‘한국의 늦가을 여행을 담은 사진풍 장면 6개, 가을 도로·기념관·호수 출렁다리·모노레일·노천 온천·밤의 리조트, 인물·문자·로고 없이 3×2 배열’이었습니다. 프로젝트에서 사용한 이미지는 `assets/`에 있습니다.

## 경로와 위치

- 용인 기본 출발·복귀점은 공공시설인 수지구청입니다. 경로 설정에서 주소와 좌표를 기기별로 지정할 수 있습니다. 주소는 사용자가 Google 지도 길찾기를 열 때 쓰이고, 좌표는 지도에 즉시 적용됩니다.
- **좌표 전송 후 도로 경로 조회**를 클릭하면 좌표가 FOSSGIS OSRM으로 전달되며 서버 로그에 남을 수 있습니다. 개략 구간만 요청하며, 요청 간격은 1.1초 이상입니다. 성공한 응답은 브라우저에 최대 7일간 캐시합니다. 파일 URL에서 브라우저가 저장소나 교차 출처 요청을 차단하면 Pages에서 열거나 GeoJSON을 사용하세요. 공개 데모의 가용성과 데이터 정확도는 보장되지 않습니다.
- **GeoJSON 경로 가져오기**는 `FeatureCollection` 안의 `LineString`과 `properties.legId`를 사용합니다. 지원 ID는 `home-rest`, `rest-monorail`, `monorail-museum`, `museum-resort`, `resort-home`입니다. 현재 방문 지점과 양 끝점이 가까운 경로를 현재 세션에 적용합니다.
- 기본 출발점을 기준으로 FOSSGIS OSRM에서 2026년 11월 17일 자동차 5개 구간을 조회해 포함했습니다. 해안선은 [Natural Earth 1:10m Land](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/)이며 배경의 등고선과 하천은 도식입니다.
- 개략 경로가 포함된 날은 이동을 시뮬레이션으로 표시합니다. 일정의 시각은 계획 기준이며, 경로와 거리에는 실시간 GPS나 교통 정보가 포함되지 않습니다.

## 화면

세로형 다크 지도에서 구간마다 다른 경로색과 파란 위치점을 표시합니다. 도착 카드가 나타날 때 카메라와 전체 경로 버튼이 위로 이동합니다. 터치 드래그·핀치, 키보드 대괄호·방향키·+/−, 모션 감소 설정을 지원합니다.
